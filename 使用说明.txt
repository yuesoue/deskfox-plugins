==============================================================
  getbot.me × OpenCode 插件安装包
==============================================================

这个插件把 getbot.me 中转接入 OpenCode 桌面 app，装完就多出：

  · 六个斜杠命令：
      /getbot-image     文生图
      /getbot-tts       语音合成
      /getbot-asr       语音识别
      /getbot-translate 中英互译（按原文自动判断方向）
      /getbot-md2html   Markdown → A4 打印排版 HTML（要 PDF 在浏览器里 Ctrl+P 另存）
      /getbot-help      使用说明（命令清单 / TTS 音色 / 默认模型 / 排查入口）
  · 快捷键 Ctrl+Shift+V ：录音 30 秒 → 自动转文字写入输入框

说明：插件配置的模型只服务于上面这些斜杠命令，不会出现在 OpenCode
主聊天界面的模型选择器里。安装脚本会自动登记到 opencode.jsonc 的
plugin 数组（自动备份原文件）。

--------------------------------------------------------------
【前置条件】
--------------------------------------------------------------

1. 已装 OpenCode 桌面 app：https://opencode.ai

2. 已装 Node.js（18 及以上）
     Windows:  https://nodejs.org 下 LTS 版一路下一步
     macOS:    brew install node
     Linux:    sudo apt install nodejs npm  （或用 nvm）

3. ffmpeg（语音合成 / 语音识别 / 语音输入用）
     Windows:  winget install Gyan.FFmpeg
     macOS:    brew install ffmpeg
     Linux:    sudo apt install ffmpeg

   不装也能装插件，安装脚本会自动检测并打印一段「AI 助理可代办的
   安装提示词」，复制给任意 AI 助理（包括 OpenCode 本身）即可让
   它自动跑包管理器装上。

4. 去 https://getbot.me 注册并拿一个 API Key（sk- 开头）

--------------------------------------------------------------
【安装步骤】
--------------------------------------------------------------

1. 把整个文件夹解压到任意位置（别删，卸载时还要用）

2. 双击：
     Windows  →  一键安装.bat
     macOS    →  install.command
                （若提示"无法打开"：右键 → 打开，或终端里跑
                  bash install.command）

3. 弹出窗口会提示：
     请粘贴 getbot.me API Key：
   粘贴 sk-xxxxxxxxx 回车即可。

4. 安装结束会显示：
     ✅ 安装完成
     已注册 6 个斜杠命令 ...
   如果检测到缺 ffmpeg / ffprobe，会顺带打印一段「AI 助理可代办的
   安装提示词」，把那段复制给你的 AI 即可一键装好。

5. 【重要】完全退出 OpenCode 桌面 app（**托盘图标也要退**），
    然后重开。不然配置不会生效。

6. 在任意项目里开一个聊天，输入 / 就能看到 /getbot-* 斜杠命令。
   不需要去「管理模型」里做任何配置。

--------------------------------------------------------------
【使用示例】
--------------------------------------------------------------

在 OpenCode 聊天框里：

  /getbot-image 一只戴眼镜的橘猫在键盘上打字，扁平插画风
    → 等几秒，图片存到当前项目的 getbot.me/image/ 下

  /getbot-tts 你好这是一段测试
    → 生成 wav，存到 getbot.me/audio/
    → 想换音色：对 AI 说"用 Ethan 念：你好"

  /getbot-asr 录音.m4a
    → 转录文字存为同名 .txt

  /getbot-translate Hello, this is a test.
    → 自动判断英→中，原地输出译文
  /getbot-translate 你好，这是测试
    → 自动判断中→英

  /getbot-md2html D:\docs\报告.md
    → 生成打印排版 HTML，自动弹出浏览器
    → 需要 PDF 按 Ctrl+P（macOS：Cmd+P）→ 另存为 PDF
    → 输出存到 getbot.me/html/

  /getbot-help
    → 显示完整命令清单、TTS 可用音色、当前默认模型、排查路径

  Ctrl+Shift+V
    → 说话 30 秒 → 自动写入输入框

--------------------------------------------------------------
【出问题怎么办（Debug 模式）】
--------------------------------------------------------------

插件默认不写日志（避免长期跑下来日志膨胀）。遇到问题时按这个流程：

  1) 对 AI 说："开 getbot 调试"
     → 自动打开 debug 日志 + 跑一次环境诊断
     → 诊断会列出 Node 版本、API Key、模型缓存、ffmpeg、写权限
       等所有依赖状态；缺什么会给可拷给 AI 的安装提示词

  2) 复现你遇到的问题（再试一次出错的命令）

  3) 对 AI 说："打开 getbot 日志文件夹"
     → 弹出文件管理器，把今日的 JSONL 日志发给开发者

  4) 排查完成后对 AI 说："关闭 getbot 调试"
     → 停止写新日志，已生成的日志文件仍保留

--------------------------------------------------------------
【卸载】
--------------------------------------------------------------

双击：
  Windows  →  一键卸载.bat
  macOS    →  uninstall.command
             （若提示"无法打开"：右键 → 打开，或终端里跑
               bash uninstall.command）

确认提示里输入 y 回车即执行。也可以命令行里跑：

    node install.mjs --uninstall

这会删掉：
  ~/.config/opencode/plugins/getbot/         （含 getbot.js / marked.mjs / package.json）
  ~/.config/opencode/command/getbot-*.md      （6 个斜杠命令文件）
  ~/.config/opencode/cache/getbot-models.json
  ~/.config/opencode/config/getbot-secret.json（含 apiKey）
  老版本残留：command/getbot-{doctor,logs}.md（旧布局，自动清理）

同时会从 opencode.jsonc 的 plugin 数组里摘掉本插件登记（自动备份）。
config/getbot.json 会保留（含用户手调参数），需彻底清就手动删。
日志文件夹 ~/.config/opencode/cache/logs/ 也不会自动删，按需手动清。

--------------------------------------------------------------
【常见问题】
--------------------------------------------------------------

Q: 重开 OpenCode 后看不到 /getbot-* 斜杠命令？
A: 1) 确认托盘里的 OpenCode 也退了（右下角系统托盘）
   2) 检查 ~/.config/opencode/command/ 下有 getbot-*.md 文件
   3) 检查 ~/.config/opencode/plugins/getbot/getbot.js 存在
   4) 检查 ~/.config/opencode/opencode.jsonc 的 plugin 数组里
      含一条 file:///.../plugins/getbot 的登记

Q: /getbot-image 报 401 / 403 ?
A: API Key 填错或已失效。重跑一次安装脚本，把新 Key 贴进去。

Q: /getbot-tts 或 /getbot-asr 报 "未检测到 ffmpeg"？
A: 按前置条件装 ffmpeg。或对 AI 说"开 getbot 调试"，诊断会给
   一段可拷的 AI 自动安装提示词。

Q: Ctrl+Shift+V 录音没反应？
A: 检查麦克风权限（macOS：系统设置 → 隐私与安全性 → 麦克风 →
   允许 OpenCode）。Windows 一般不用特别配。

Q: 我想看完整命令清单和当前默认模型？
A: 在 OpenCode 聊天框里输 /getbot-help

--------------------------------------------------------------
【安全说明】
--------------------------------------------------------------

API Key 明文保存在 ~/.config/opencode/config/getbot-secret.json
的 apiKey 字段。该文件在你的个人用户目录，只有你和管理员能读。
切勿把这个文件传给别人或提交到公共仓库。

本脚本不会把 Key 写进 OpenCode 主配置 opencode.jsonc，所以你
可以放心分享 / 版本化 opencode.jsonc 而不泄露 Key。

更新 Key：再跑一次安装脚本，它会覆盖旧 Key。
